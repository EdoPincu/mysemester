# mysemester

A semester schedule planner. Pick a time slot for each course and it shows you clashes, free days and exam spacing.

**Live:** https://edopincu.github.io/mysemester/

- **Profiles:** each person picks or creates a profile when the page opens, like Netflix. There's no email and no password.
- **Local storage only:** all data stays in the browser's `localStorage` on the machine that opens it. To move plans between computers, use Export / Import.
- **Desktop layout:** the course list and the calendar scroll separately.
